# Banking System with JDBC 
A simple Banking Management System developed using 
java and JDBC with PostgreSQL.
## Features
- Create customer account
- View customer information
- Upload customer information
- Connect java application with PostgreSQL database
- Perform database operations using JDBC

  ## Technologies Used
  - java
  - JDBC
  - PostgreSQL
  - vs Code

  ## Database
  PostgreSQL is used as the database.

 ## Project Structure
 -CustomersDetails.class
 -LICENSE - MIT licence

 ## How to Run
 1. Install java jdk
 2. install PostgreSQL.
 3. Create the required database and tables.
 4. Configure PostgreSQL username, password and database URL in the java code.
 5. Add the PostgreSQL JDBC Driver.
 6. Compile and run the java application
